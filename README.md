## how to build

Requires **JDK 25**
low iq

```bash
./gradlew build
```

Output: `build/libs/openkuroplus-mc26.1.2-1.0.0.jar`

## how to run

1. Fabric Loader **0.19.2+** for MC 26.1.2
2. Fabric API (any recent 26.x build)
3. jar goes in `mods/`. you know the rest.
